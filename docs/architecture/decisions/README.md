# Architecture Decision Records

These ADRs record the **Phase 0 recommendations updated by Phase 1 source research**. Phase 2 implemented and tested the local domain/database foundation; it did not provision production services, authorize source ingestion or build the frontend. See [domain-model.md](../domain-model.md), [database.md](../database.md) and [api.md](../api.md) for the Phase 2 deliverables. Phase 1 source, cost and licence findings are documented in [data-sources.md](../../data-sources.md), [data-source-matrix.md](../../data-source-matrix.md), [data-cost-model.md](../../data-cost-model.md), [data-licensing.md](../../data-licensing.md) and [official-resort-source-policy.md](../../official-resort-source-policy.md).
